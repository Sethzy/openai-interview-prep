# Kellblog: Stop Making the Number One Mistake in Presentations

## Summary

The most common presentation error is beginning with existing slides rather than with the audience and the result the presentation must create. Material designed for analysts, operators, product managers or another customer carries assumptions that may be wrong for the current room.

Kellogg's practical sequence is:

1. Define the audience.
2. Define what they need to understand, believe or decide.
3. Start with a blank presentation.
4. Build the narrative as an outline, often using slide titles.
5. Revise the structure before polishing slides.
6. Reuse existing material only after the narrative is clear and only when it serves the current audience.

## OpenAI Interview Relevance

This sharpens [[OpenAI-SDR-final-sales-acumen-interview-pack#47A. How do you prepare for an important customer meeting or presentation?|the important-meeting preparation answer]]. The existing Pre-Wire Check stress-tests the narrative; this article defines how to build that narrative in the first place.

The interview-ready principle is:

> [!quote] Audience-backward construction
> “they start with what they have -- instead of starting with what's needed.”

For a customer meeting, the seller should begin with the customer's decision, concerns and desired outcome. For an executive interview or presentation, the same rule applies: build the structure around what that audience must evaluate rather than repurposing the most convenient existing deck.

## Relevance Boundary

This is a strong presentation-construction heuristic, not a rule against all slide reuse. Existing proof, visuals and approved content remain useful after the audience-specific narrative has been designed.
